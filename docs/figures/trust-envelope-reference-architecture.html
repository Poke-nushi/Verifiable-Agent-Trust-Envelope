VATE · v0.3 reference architecture

Declare the request basis. Decide locally. Link the outcome.

VATE is the verifier-side admission and receipt boundary. It evaluates one declared request basis with digest-addressed, protocol-native evidence references and records one local decision. An implementation-owned gate controls handoff; later outcome evidence links back to the admitted basis.

Swipe horizontally to inspect the full diagram.

Profile flow

Admission request → ordered local checks → admission receipt → implementation-owned handoff gate → target or stop → linked post-execution receipt.

Adjacent systems

Transport, identity, authorization, payment, attestation, permission, and execution systems retain their own semantics and validation duties.

Review claim

This is a discussion-draft architecture and interoperability review aid, not a production verifier, endorsement, or general compatibility proof. Portable fresh-permit successor lineage is not defined.
