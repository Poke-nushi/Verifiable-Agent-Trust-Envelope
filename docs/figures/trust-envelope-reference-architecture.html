VATE · v0.3 reference architecture

Declare the request basis. Decide locally. Link the outcome.

The receiving system evaluates one agent request and its evidence under local policy. A VATE admission receipt records that decision. The deployment controls handoff. A later outcome receipt can link back to the admission and the instructions it approved.

Scroll horizontally to inspect the full diagram.

Purchase request binding

In the v0.7.0 purchase example, the receiver checks the receipt against its selected admission request and both sets of instructions. Applying the recorded limit change to the original reproduces the approved instructions.

Adjacent systems

Transport, identity, authorization, payment, attestation, permission, and execution systems retain their own semantics and validation duties.

Review claim

This is a discussion-draft architecture and interoperability review aid, not a production verifier, endorsement, or general compatibility proof. Portable fresh-permit successor lineage is not defined.
